# sales-performance-dashboard-sql-powerbi
# Sales Performance Dashboard using SQL & Power BI

## Project Overview

This project focuses on analyzing e-commerce sales data using SQL and visualizing key business metrics through an interactive Power BI dashboard.

## Tools & Technologies

- SQL (MySQL)
- Power BI

## SQL Analysis Performed

- Total Revenue
- Total Orders
- Revenue by Category
- Revenue by State
- Monthly Revenue Trend
- Cancellation Rate Analysis
- Top Cities by Revenue
- Average Order Value

## Dashboard KPIs

- Total Revenue
- Total Orders
- Cancellation Rate

## Dashboard Features

- Category Filter
- State Filter
- Date Filter
- Revenue Trend Analysis
- Regional Performance Analysis
- Category-wise Performance Analysis

## Key Insights

- Set category contributed the highest revenue.
- Maharashtra generated the highest sales.
- Cancellation rate was approximately 7–14% depending on the filtered dataset.
- Revenue was concentrated in a few major categories and regions.

## Business Impact

The dashboard enables stakeholders to monitor business performance and make data-driven decisions through interactive visualizations.
